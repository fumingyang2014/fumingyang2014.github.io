# 裴蜀定理
【OI考点】 

对于 $\forall x,y\in\mathbb{Z}$

若 $a,b\in\mathbb{Z}$ 且不同时为 $0$，函数 $f(x,y)=ax+by$ 的最小正整数取值为 $\gcd(a,b)$。

# 中国剩余定理-CRT
$$
\begin{cases}
x\equiv2\pmod{3}\\
x\equiv3\pmod{5}\\
x\equiv2\pmod{7}
\end{cases}
$$

```cpp
LL CRT(int k, LL* a, LL* r) {
  LL n = 1, ans = 0;
  for (int i = 1; i <= k; i++) n = n * r[i];
  for (int i = 1; i <= k; i++) {
    LL m = n / r[i], b, y;
    exgcd(m, r[i], b, y);  // b * m mod r[i] = 1
    ans = (ans + a[i] * m * b % n) % n;
  }
  return (ans % n + n) % n;
}
```
