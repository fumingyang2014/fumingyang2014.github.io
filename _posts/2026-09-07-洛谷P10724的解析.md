核心思想是：**只关心每个质因子的指数奇偶性**。

## 1. 为什么只看指数的奇偶性？

一个数是完全平方数，当且仅当它的质因数分解中，每个质因子的指数都是偶数。

例如：

```text
12 = 2^2 × 3^1
```

因为 `3` 的指数是奇数，所以不是平方数。

```text
36 = 2^2 × 3^2
```

所有指数都是偶数，所以是平方数。

---

## 2. `pw2` 是干什么的？

代码中：

```cpp
pw2[0] = 1;
for (int i = 1; i < 10; i++)
    pw2[i] = pw2[i - 1] * 2;
```

得到：

```text
pw2[0] = 1       // 二进制第 0 位
pw2[1] = 2       // 二进制第 1 位
pw2[2] = 4       // 二进制第 2 位
pw2[3] = 8       // 二进制第 3 位
...
```

它们实际上是：

```cpp
pw2[j] = 1 << j;
```

用于给每个质数分配一个二进制位：

| 质数 | 对应位 | 权值 |
|---|---:|---:|
| 2 | 第 0 位 | 1 |
| 3 | 第 1 位 | 2 |
| 5 | 第 2 位 | 4 |
| 7 | 第 3 位 | 8 |

例如，某个数中：

```text
2 的指数为奇数
3 的指数为偶数
5 的指数为奇数
```

就可以用二进制：

```text
101
```

表示，也就是：

```text
1 + 4 = 5
```

因此，`cnt` 是一个二进制状态，用来记录各个质因子指数的奇偶性。

---

## 3. 为什么使用异或 `cnt ^= pw2[j]`？

代码：

```cpp
while (x % primes[j] == 0) {
    x /= primes[j];
    cnt ^= pw2[j];
}
```

每发现一个质因子，就把对应的二进制位翻转一次。

例如：

```text
x = 12 = 2^2 × 3
```

处理质因子 `2`：

```text
cnt: 000
第一次遇到 2：001
第二次遇到 2：000
```

说明 `2` 的指数为偶数。

处理质因子 `3`：

```text
cnt: 000
遇到 3：010
```

最终状态为 `010`，表示：

```text
2 的指数是偶数
3 的指数是奇数
```

这正好对应 `12` 不是完全平方数。

如果一个质因子出现偶数次，由于异或两次会抵消：

```text
1 ^ 1 = 0
```

所以异或天然适合记录奇偶性。

---

## 4. 区间如何转化为前缀状态？

设 `pre[i]` 表示：

```text
a1 × a2 × ... × ai
```

中所有质因子指数奇偶性的状态。

区间 `[l,r]` 的状态为：

```text
pre[r] XOR pre[l-1]
```

如果区间乘积是完全平方数，那么所有指数都必须为偶数，也就是状态为 `0`：

```text
pre[r] XOR pre[l-1] = 0
```

异或结果为 `0`，等价于：

```text
pre[r] = pre[l-1]
```

所以问题变成：

> 统计有多少对前缀状态相同。

---

## 5. 为什么先执行：

```cpp
ans += _hash[cnt];
```

`_hash[cnt]` 表示：

> 当前之前，已经出现过多少次状态 `cnt`。

假设当前状态是 `cnt`，如果之前有 `k` 个前缀状态也等于 `cnt`，那么它们都能和当前前缀组成一个合法区间，因此应该贡献 `k` 个答案：

```cpp
ans += _hash[cnt];
```

然后再把当前状态记录进去：

```cpp
_hash[cnt]++;
```

顺序必须如此。

### 举例

假设前缀状态依次为：

```text
0, 3, 3
```

处理第二个 `3` 时，之前有一个 `3`：

```cpp
ans += _hash[3];  // 加 1
_hash[3]++;       // 再记录当前这个 3
```

这对应一个区间。

如果先增加：

```cpp
_hash[cnt]++;
ans += _hash[cnt];
```

那么当前前缀会把自己也算进去，相当于错误地统计了：

```text
[l, r] 中 l = r + 1
```

这种不存在的区间。

所以正确顺序是：

```cpp
ans += _hash[cnt];  // 只和之前的前缀匹配
_hash[cnt]++;       // 再加入当前前缀
```

---

## 6. 为什么要有：

```cpp
_hash[0] = 1;
```

它表示空前缀：

```text
pre[0] = 0
```

这样，如果某个前缀本身就是完全平方状态 `0`，就可以和空前缀匹配，表示区间：

```text
[1, r]
```

例如第一个数是 `4`：

```text
pre[1] = 0
```

因为：

```cpp
ans += _hash[0];  // 加 1
```

就统计到了区间 `[1,1]`。

---

另外，你文件中的这两处应为：

```cpp
int cnt = 0;
```

以及：

```cpp
cnt ^= pw2[j];
```

而不是：

```cpp
cnt[j] = 0;
```

因为 `cnt` 应该是一个整数二进制状态，不是数组。
