# 树形dp
## 前置知识
### 树的DFS遍历
树是无环连通图。用 DFS 遍历，**后序遍历**：先递归完所有子树，再回到当前节点——这正是树形 DP 的顺序基础。注意记录父节点防止走回头路。
### 动态规划三要素
任何 DP 都要回答三个问题：**状态是什么**（dp 数组表示什么）、**转移怎么推**（由什么状态得到）、**边界和顺序是什么**（初值、遍历次序）。树形 DP 也不例外。
### 背包模型
01 背包（选/不选）与**分组背包**（每组至多选一个）是树上背包的母模型。核心技巧：**容量倒序枚举**，避免重复选择。
## 什么是树形dp
### 💡 核心思想
把树看作**父子层级结构**。父节点的状态只与它的子树有关，因此可以：
```cpp
先算子树 → 合并到父节点 → 自底向上，层层递推
```
形式上，它就是在 DFS 的**回溯阶段（后序）**执行状态转移。树的天然递归结构，决定了「树形 DP 几乎总是用递归实现」。

> 口诀：先小后大，先子后父；后序遍历，自底向上；状态想清楚，转移写出来；递归记得传爸爸。

### 🧠 什么时候用树形 DP？
+ 问题的结构是树 / 森林，答案与「父子关系」或「子树」有关；
+ 需要求「以每个点为根的子树内」的最优值 / 方案数 / 信息合并；
+ 需要在树上做「选或不选」「分配资源（背包）」「路径统计」等决策。

*下面我们用 5 个经典模型，把树形 DP 的每种套路走一遍。*

## 经典模型①：没有上司的舞会

### 📖 题目描述（洛谷 P1352）[link](https://www.luogu.com.cn/problem/P1352)

某公司有 n 名职员，构成一棵树：每个职员都有唯一的直接上司。要举办一场舞会，如果某个职员**来了**，那么他的**直接下属**就不能来。每个职员 i 有一个快乐值 w[i]，求参加舞会人员的快乐值总和最大是多少。

> **本质**：在一棵树上选一些点，**相邻两点不能同时选**，求选中点权值和的最大值 —— 树的「最大权独立集」。

### 🎨 状态设计与转移

子问题：只考虑「以 u 为根的子树」，答案取决于 u 来不来——所以加一维：
```cpp
dp[u][0] = u 不参加时，子树内最大快乐值
dp[u][1] = u 参加时，子树内最大快乐值
```
```cpp
dp[u][0] = Σv∈son(u) max(dp[v][0], dp[v][1])
dp[u][1] = w[u] + Σv∈son(u) dp[v][0]
```
转移逻辑：u 不来 → 孩子来不来都行，取更大；u 来 → 孩子一律不能来，加上自己的快乐值。最后答案：max(dp[root][0], dp[root][1])。
> **易错点**：① 树是「无向」存边，DFS 必须记录 fa 防回头；② 要自己找根（入度为 0 的节点）；③ 快乐值可能是负数，初始化注意。

AC Code:
```cpp
#include<iostream>
#include<cstdio>
using namespace std;

int const maxn=10011;
int f[maxn][5],fa[maxn],num[maxn],son[maxn][maxn];
bool kid[maxn];
int n,v,x,y;

void dfs(int u){
	if(!son[u][0]){
		f[u][1]=num[u];
		f[u][0]=0;
		return;
	}
	else{
		for(int i=1;i<=son[u][0];i++){
			dfs(son[u][i]);
			f[u][0]+=max(f[son[u][i]][0],f[son[u][i]][1]);
			f[u][1]+=f[son[u][i]][0];
		}
		f[u][1]+=num[u];
	}
}

int main(){
	cin>>n;
	 for(int i=1;i<=n;i++){
        cin>>v;
    	num[i]=v;
	}
	for(int i=1;i<n;i++){
		cin>>x>>y;
		son[y][0]++;
		fa[x]++;
		son[y][son[y][0]]=x;
	}
	cin>>x>>y;
	int root;
	for(int i=1;i<=n;i++)
		if(!fa[i]){
			root=i;
			break;
		}
	dfs(root);
	cout<<max(f[root][0],f[root][1]);
	return 0;
}

```

## 经典模型 ②：树的直径
### 📖 问题描述
在一棵 n 个节点的树中，找到一条**最长的简单路径**，这条路径的长度（经过的边数 / 边权和）称为树的直径。树可能不唯一。

> 重要性质：直径一定可以表示为「某个节点 u 的两条最长向下的链在 u 处拼接」——这是树形 DP 解法的依据。

### 🎨 两种经典解法

| 方法 | 做法 | 复杂度 | 特点 |
| --- | --- | --- | --- |
| 两边dfs/bfs | 任取一点出发找最远点 a，再从 a 出发找最远点 b，a→b 即直径 | O(n) | 只能处理无权/边权为正；能顺便输出路径 |
| 树形dp | f[u] = u 向下最长链，ans = max(d1 + d2) | O(n) | 适用于边权可负、树不连通等一般情况 |

```cpp
f[u] = max(f[v] + w(u,v))
ans = maxu ( 最长链 d1 + 次长链 d2 )
```

后序遍历每个节点 u，统计子树内传给 u 的链长（每条 = f[v]+1），取最长 d1、次长 d2，则经过 u 的最长路径 = d1 + d2，用它更新全局答案 ans。

### 参考代码（树形dp）
```cpp
int n, ans; f[N]; vector<int> g[N];

void dfs(int u, int fa) {

    int d1 = 0, d2 = 0;              // 最长、次长向下链

    for (int v : g[u]) {

        if (v == fa) continue;

        dfs(v, u);

        int len = f[v] + 1;           // 经过 v 传给 u 的链长

        if (len > d1) d2 = d1, d1 = len;  // 更新最长（原最长变次长）

        else if (len > d2) d2 = len;      // 更新次长

    }

    f[u] = d1;                        // u 的向下最长链

    ans = max(ans, d1 + d2);       // 经过 u 的最长路径

}
```
复杂度 O(n)。边权可正可负，直接改成 f[v] + w(u,v) 即可。

## 经典模型③：树上背包（选课）
### 📖 题目描述（洛谷 P2014 选课）
有 n 门课程，每门课有先修课（先修关系构成一棵树，没有先修课的以虚拟根 0 为父）。每门课 i 有学分 w[i]，你最多选 m 门课，且**选了某门课必须先选它的先修课**。求最多能拿多少学分。

> 本质：在树上「分配名额」——每个节点选与不选会影响后代能否选，这是典型的**树形分组背包**。

### 🎨 状态设计与转移
```cpp
dp[u][j] = 以 u 为根的子树中，恰好选 j 门课（含 u 本身）能获得的最大学分
```

先把 dp[u][1] = w[u]（只选 u 自己）。然后对每个孩子 v，做一次**分组背包合并**：在 u 已选的 j 门基础上，再决定从 v 的子树里选 k 门。

```cpp
dp[u][j+k] = max( dp[u][j+k], dp[u][j] + dp[v][k] )
```
> **关键细节**：j 必须倒序枚举（01 背包语义，避免 u 复用同一个子树多次）；虚拟根 0 也要占 1 个名额，所以答案取 dp[0][m+1]。

### 💻 参考代码（C++）
```cpp
int n, m, w[N], dp[N][M];

vector<int> g[N];               // 0 为虚拟根

void dfs(int u) {

    dp[u][1] = w[u];                // 只选 u 自己

    for (int v : g[u]) {

        dfs(v);                    // 先算出子树的背包

        for (int j = m; j >= 1; j--)          // ★ 倒序！

            for (int k = 1; j + k <= m; k++)

                dp[u][j + k] = max(dp[u][j + k],

                                   dp[u][j] + dp[v][k]); // 分组背包合并

    }

}

// 答案：cout << dp[0][m+1];（虚拟根 0 占用 1 个名额）
```
*朴素复杂度 O(n·m²)。优化：合并时 j 的下界取「当前已并入的子树大小和」，可使总复杂度降到 O(n·m)。下面给出严格证明。*

### 📐 树上背包复杂度详解：为什么是 O(n·m) 而不是 O(n·m²)？

#### ① 朴素写法：O(n·m²)

如果合并子树 v 时，j 和 k 都从 1 枚举到 m（只做 j+k ≤ m 的剪枝）：
```cpp
每合并一条边 (u,v) 耗时 O(m²) → 树有 n−1 条边 → 总复杂度 O(n·m²)
```
当 n = m = 300（如 P2014）时，300 × 300² ≈ 2.7×10⁷，勉强可过；n、m 再大就不可行——所以必须做上下界优化。

#### ② 上下界优化：单次合并代价降到 ≤ m × sz[v]

让 **j 只枚举到"u 当前已并入的节点数cur"**（dp[u][j] 在 j > cur 时本来全是 −∞，枚举无意义），**k 只枚举到 sz[v]：**
```cpp
单次合并代价 = min(cur, m) × min(sz[v], m) ≤ m × sz[v]
```
直觉：左侧容量只有 m 种取值，右侧 k 最多 sz[v] 种取值——子树再大，k 也不会超过它的节点数。

#### 归纳证明：T(u) = O(m·sz[u])
记 T(u) 为「以 u 为根的子树**内部所有合并**的总代价」，则对每个孩子 v：
```cpp
T(u) = Σv∈son(u) [ min(cur, m)·min(sz[v], m) + T(v) ]
```

+ 单步上界：min(cur, m)·min(sz[v], m) ≤ m·sz[v]（因为 min(cur,m) ≤ m，min(sz[v],m) ≤ sz[v]）；
+ 归纳假设：叶子节点 T = 0；假设所有孩子的 T(v) ≤ m·sz[v]；
+ 递推：T(u) ≤ Σv( m·sz[v] ) + Σv( m·sz[v] ) = 2m·(sz[u] − 1) ≤ 2m·sz[u]；
+ 结论：T(root) ≤ 2m·n = O(n·m)，证毕。

> **一句话记忆**：合并孩子 v 的代价 ≤ m·sz[v]，相当于给 v 子树内的每个点记 O(m) 的账；每个点只会在「作为某棵子树的一员被并入父节点」时记一次账，所以总账 ≤ m·n = O(n·m)。

> **边界情形**：当 m ≥ n（容量不小于节点数）时，min 截断失效，复杂度退化为点对数量级 O(n²)——这正是网上流传的「点对」说法只在大 m 时成立的原因；常规题目 m ≪ n，此时才是 O(n·m)。
