# 树形dp
## 前置知识
### 树的DFS遍历
树是无环连通图。用 DFS 遍历，**后序遍历**：先递归完所有子树，再回到当前节点——这正是树形 DP 的顺序基础。注意记录父节点防止走回头路。
### 动态规划三要素
任何 DP 都要回答三个问题：**状态是什么**（dp 数组表示什么）、**转移怎么推**（由什么状态得到）、**边界和顺序是什么**（初值、遍历次序）。树形 DP 也不例外。
### 背包模型
01 背包（选/不选）与**分组背包**（每组至多选一个）是树上背包的母模型。核心技巧：**容量倒序枚举**，避免重复选择。
## 什么是树形dp
### 💡 核心思想
把树看作**父子层级结构**。父节点的状态只与它的子树有关，因此可以：
```cpp
先算子树 → 合并到父节点 → 自底向上，层层递推
```
形式上，它就是在 DFS 的**回溯阶段（后序）**执行状态转移。树的天然递归结构，决定了「树形 DP 几乎总是用递归实现」。

> 口诀：先小后大，先子后父；后序遍历，自底向上；状态想清楚，转移写出来；递归记得传爸爸。

### 🧠 什么时候用树形 DP？
+ 问题的结构是树 / 森林，答案与「父子关系」或「子树」有关；
+ 需要求「以每个点为根的子树内」的最优值 / 方案数 / 信息合并；
+ 需要在树上做「选或不选」「分配资源（背包）」「路径统计」等决策。

*下面我们用 5 个经典模型，把树形 DP 的每种套路走一遍。*

## 经典模型①：没有上司的舞会

### 📖 题目描述（洛谷 P1352）[link](https://www.luogu.com.cn/problem/P1352)

某公司有 n 名职员，构成一棵树：每个职员都有唯一的直接上司。要举办一场舞会，如果某个职员**来了**，那么他的**直接下属**就不能来。每个职员 i 有一个快乐值 w[i]，求参加舞会人员的快乐值总和最大是多少。

> **本质**：在一棵树上选一些点，**相邻两点不能同时选**，求选中点权值和的最大值 —— 树的「最大权独立集」。

### 🎨 状态设计与转移

子问题：只考虑「以 u 为根的子树」，答案取决于 u 来不来——所以加一维：
```cpp
dp[u][0] = u 不参加时，子树内最大快乐值
dp[u][1] = u 参加时，子树内最大快乐值
```
```cpp
dp[u][0] = Σv∈son(u) max(dp[v][0], dp[v][1])
dp[u][1] = w[u] + Σv∈son(u) dp[v][0]
```
转移逻辑：u 不来 → 孩子来不来都行，取更大；u 来 → 孩子一律不能来，加上自己的快乐值。最后答案：max(dp[root][0], dp[root][1])。
> **易错点**：① 树是「无向」存边，DFS 必须记录 fa 防回头；② 要自己找根（入度为 0 的节点）；③ 快乐值可能是负数，初始化注意。

AC Code:
```cpp
#include<iostream>
#include<cstdio>
using namespace std;

int const maxn=10011;
int f[maxn][5],fa[maxn],num[maxn],son[maxn][maxn];
bool kid[maxn];
int n,v,x,y;

void dfs(int u){
	if(!son[u][0]){
		f[u][1]=num[u];
		f[u][0]=0;
		return;
	}
	else{
		for(int i=1;i<=son[u][0];i++){
			dfs(son[u][i]);
			f[u][0]+=max(f[son[u][i]][0],f[son[u][i]][1]);
			f[u][1]+=f[son[u][i]][0];
		}
		f[u][1]+=num[u];
	}
}

int main(){
	cin>>n;
	 for(int i=1;i<=n;i++){
        cin>>v;
    	num[i]=v;
	}
	for(int i=1;i<n;i++){
		cin>>x>>y;
		son[y][0]++;
		fa[x]++;
		son[y][son[y][0]]=x;
	}
	cin>>x>>y;
	int root;
	for(int i=1;i<=n;i++)
		if(!fa[i]){
			root=i;
			break;
		}
	dfs(root);
	cout<<max(f[root][0],f[root][1]);
	return 0;
}

```
